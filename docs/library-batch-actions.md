# Library batch actions

Select assets or shots using the corner checkbox or the Library Select control. Select all shown follows the current search and filters. Changing the project, source project or Library tab clears the selection.

Download writes separate full-size image files or MP4s to a folder chosen through the browser. For shots, the approved take is preferred; otherwise the latest completed take is used. Files without a completed output are omitted. Existing filenames are preserved and new collisions receive (1), (2), etc. Browsers without the folder API use ordinary browser downloads, with their own destination and multiple-download settings. No ZIP is created by the Download button.

Delete confirms once and refuses active generations. Asset deletion archives linked studies and removes current reference bindings through the existing asset deletion path. The complete selection is validated before saving. Deletion is available in the current project; open another project before deleting its assets.

Click feedback preserves anchored control positions. Model settings keep SelfLift compact and source links grouped below the selectors. Omni REF selects its VSA recipe automatically without an extra control; base H3 uses its original recipe.

Validation: live two-item selection in both Library tabs; isolated asset deletion fixtures for linked history, reference cleanup, active work and invalid IDs; filename collision/cancellation fixtures; JavaScript syntax. Package checks use a fake engine without GPU generation.
