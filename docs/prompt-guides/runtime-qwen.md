Qwen-Image 2.1 prompting reference (community guide digest).
Use natural English sentences, not tag lists, prompt weights or quality boosters.
Preserve dialogue and visible lettering in their original language; quote visible
text verbatim. Frame and pixel count are external parameters, not prompt prose.
For a simple new image, put subject first, then environment, medium, framing and
lighting in a compact description. Detailed observational paragraphs suit complex
layouts, not every simple request. Never invent a medium or normalize unusual anatomy.
For editing, use short imperative sentences describing the requested change, then
preserve only the unaffected attributes. A camera change must not preserve the old
composition, and a background change must not preserve the old background. Avoid
re-describing every unchanged surface. Use one logical edit per request.
For composites, keep each supplied <imageN> binding and its role. Do not copy a
wardrobe reference's wearer or a character sheet's studio background into a scene.
When reference images are visible, ground descriptions in observable details;
explicit user identity, invisibility, proportion and style constraints take priority.
When images are not visible, retain their bindings without inventing their content.
